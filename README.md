# 🤌 FUGGEDABOUTIT MESH 🇺🇸

### No towers. No service. No problem. **Fuggedaboutit.**

**AYYY, HOW YOU DOIN'?** Welcome to **Fuggedaboutit Mesh**, the Garden State-inspired Android mesh-radio client. Whether you're on the Parkway, stuck at a jughandle, or headed down the Shore, stay in touch over compatible Meshtastic radios when cell service decides to take the day off.

> **Status:** Rebranding in progress. This fork currently inherits upstream Meshtastic functionality and branding in parts of the app. The Jersey interface, icon and independent APK are planned, not yet shipped.

## 🍕 What's cookin', paisan?

Built on the open-source Meshtastic Android client, this fork aims to keep the serious radio stuff working while giving the experience a little Jersey personality:

- 📡 **The Crew:** Discover nearby mesh nodes.
- 💬 **Yo, You There?:** Send and receive messages.
- 🗺️ **What Exit?:** Explore location and map features.
- 🤌 **The Neighborhood:** Connect through channels.
- 🚦 **Parkway Patrol:** See device and network status.
- 🌊 **Down the Shore:** Share waypoints and location where supported.

*These are proposed themed labels, not a claim that all screens have already been renamed.*
